# Suite de Herramientas de IA y Automatización (`ia-tools`)

Este directorio contiene herramientas modulares, probadas y seguras para enriquecer tus desarrollos presentes y futuros.

---

## 📁 Estructura

```
ia-tools/
├── firecrawl/      # Extractor web inteligente que convierte sitios a Markdown limpio para LLMs
└── n8n/            # Servidor local de flujos de trabajo visuales, webhooks e integraciones con IA
```

---

## 🛠️ Resumen de Capacidades

| Herramienta | Ubicación | Cuándo usarla |
| :--- | :--- | :--- |
| **Firecrawl** | [`ia-tools/firecrawl/`](./firecrawl/) | Cuando necesites scrapear o indexar información de páginas web complejas sin lidiar con HTML roto ni bloqueos. |
| **n8n** | [`ia-tools/n8n/`](./n8n/) | Cuando quieras conectar bases de datos, APIs, correos o bots de Telegram de forma visual sin escribir código repetitivo. |
